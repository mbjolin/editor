= editor-doc

J'attends la soutenance avant de déposer les fichiers.

Cette preuve de concept a été développée dans le cadre d'une maîtrise en informatique. Ainsi, le contenu de ce mémoire compose une partie importante de la documentation. D'où une copie de celui-ci..

== Prérequis

Overleaf ou éditeur LateX permettant de rouler le moteur pdfLateX version Legacy de 2021.

== Construction

Avec Overleaf, je n'ai pas tenté de compiler en ligne de commande pour le moment.

== Usage

Une version du rendu pdf est déposée dans le répertoire Result.
